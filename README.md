# KinoPub MSX

Приложение для [Media Station X](https://msx.benzac.de/info/) (MSX): каталог KinoPub на телевизоре и просмотр с отметками прогресса. Своего сервера нет — это статический плагин на GitHub Pages: `https://osmaevrsh.github.io/msx/`.

Статус: все разделы приложения готовы и проверены автотестами против mock API KinoPub и в web-версии MSX. Полевой тест на телевизоре (Phase 0, раздел «Диагностика») ещё не проведён: до него отдельные развилки работают со значениями по умолчанию.

## Что это и как работает

- **MSX** — медиаплеер-оболочка для Smart TV (на Samsung — из Samsung Apps). Он рисует меню, сетки плиток и плеер, а содержимое берёт у плагина.
- **Плагин** — этот проект: `index.html` и бандл `app/app.js` на GitHub Pages. MSX загружает его в фоне при старте и держит, пока открыта MSX. Плагин сам ходит в API KinoPub, строит экраны и отдаёт их MSX.
- **Сервера нет.** Телевизор обращается к API KinoPub напрямую (API разрешает такие запросы — CORS). Прогресс просмотра и закладки хранятся в аккаунте KinoPub, поэтому они общие с другими вашими устройствами. Токены входа и кэш — в памяти телевизора.
- **Каждый телевизор — отдельное устройство KinoPub** со своим входом. Выход на одном телевизоре не затрагивает другие.
- Видео играет встроенный плеер MSX (на Samsung — AVPlay) прямо с CDN KinoPub.
- Экран «Диагностика» (проверки и отчёт) — отдельный файл `app/probe.js`, он загружается только при первом открытии.

Подробная архитектура — [docs/architecture-client.md](docs/architecture-client.md).

## Что нужно

### Телевизор и MSX

- Samsung Smart TV 2025–2026 (Tizen 9/10) с **Media Station X 0.1.165** или новее — целевая платформа. На других платформах MSX приложение не проверялось.
- Браузер на компьютере (Chrome) — для запуска без телевизора и для web-пробника.

### Доступ к KinoPub

Телевизор должен видеть KinoPub напрямую: VPN на роутере или podkop. Через VPN должны идти домены:

| Домен | Зачем |
|---|---|
| `service-kp.com` | API KinoPub (`api.service-kp.com`) |
| `srvkp.com` | резервный хост API (`api.srvkp.com`) |
| `kino.watch` | страница входа по коду и список устройств |
| `kino.pub` | сайт KinoPub |
| `cdntogo.net` | видео (CDN) |
| `staticpop.net` | постеры и фоны |
| `github.io` | сам плагин (GitHub Pages) |
| `benzac.de` | MSX: словарь, ресурсы, web-версия |

### Аккаунт KinoPub и слоты устройств

Нужна активная подписка KinoPub. Каждый телевизор занимает в аккаунте свой слот устройства, а на аккаунт их около пяти. Перед установкой откройте на `kino.watch` список устройств и удалите неиспользуемые. Вход из браузера (web-версия MSX) — ещё одно устройство; освобождайте его кнопкой «Выйти из KinoPub», когда закончите.

## Установка на телевизор

1. Samsung Apps → **Media Station X** → установить и открыть.
2. Settings → **Start Parameter** → **Setup** → ввести `osmaevrsh.github.io` и включить **замок** (https).
3. MSX покажет «KinoPub MSX» с номером версии → подтвердить.
4. Откроется меню с пунктом «Вход» — дальше раздел «Вход в KinoPub».

Второй телевизор — те же шаги, свой вход и своё устройство KinoPub.

Если вы публикуете свою копию под другим логином GitHub или с другим именем репозитория, что вводить на телевизоре, подскажет `npm run tv-address -- <login> [repo]`. Если в логине есть дефис, при вводе с пульта он превращает следующую букву в заглавную. Тогда, если адрес на экране не совпал буква в букву, нужна короткая ссылка `id:igd:<alias>` на is.gd — команда объясняет, как её сделать.

**Обновления.** Новая версия доходит до телевизора в течение 10 минут после деплоя. MSX, открытая дольше, держит старую версию до перезапуска.

## Запуск в браузере

Тот же плагин работает в web-версии MSX. Откройте в Chrome:

```text
https://msx.benzac.de/?start=menu:request:interaction:init@https://osmaevrsh.github.io/msx/app/index.html
```

Управление — стрелки, Enter и Backspace («Назад»). Домены KinoPub должны идти через VPN так же, как у телевизора. Вход из браузера занимает слот устройства — после работы выйдите: «Диагностика» → «Выйти из KinoPub».

## Вход в KinoPub

1. Меню → «Вход». На экране — адрес `kino.watch/device` и код из букв и цифр.
2. На телефоне или компьютере откройте `kino.watch/device`, войдите в KinoPub и введите код.
3. Телевизор сам проверяет код каждые несколько секунд; «Проверить сейчас» — проверить сразу, «Новый код» — если код истёк.
4. После подтверждения — «Вход выполнен», меню перестраивается: «Главная», «Поиск», каталог, «Закладки», «Просмотр и аккаунт».

Устройство появится в списке на `kino.watch` под именем «MSX <модель телевизора>». Повторно входить не нужно: токены хранятся на телевизоре и обновляются сами. Если телевизор не включали больше 30 дней или устройство удалили на `kino.watch`, приложение попросит войти снова.

## Возможности

- **Главная** — полки «Продолжить просмотр», «Новые фильмы», «Новые сериалы», «Закладки», «Популярные фильмы», «Популярные сериалы», «Горячее: фильмы», «Горячее: сериалы». Полка — ряд крупных постеров (6 в ряду), последняя плитка «Показать все» открывает полный список. Открывается сразу из кэша и обновляется в фоне; без связи показывает сохранённое с пометкой «нет связи».
- **Каталог** — «Фильмы», «Сериалы», «Мультфильмы», «Документальное», «ТВ-шоу», «Концерты». Крупные постеры по 6 в ряд, под ними название в две строки, год и рейтинг; полное название плитки в фокусе — в заголовке. Список догружается при прокрутке; «вверх» на первом ряду и «вниз» на последнем никуда не уводят. Красная кнопка — сортировка (обновлённые, рейтинг КП и др.) и жанр; текущие значения и число найденного — в строке над сеткой.
- **Поиск** — экранная клавиатура (русская и английская раскладки, цифры; цифры можно вводить и кнопками пульта). Поиск начинается с двух символов, через полсекунды после последнего нажатия.
- **Карточка** — описание, рейтинги, главная кнопка: «▶ Смотреть», «▶ Продолжить с 19:57», «▶ Продолжить: 1 сезон, 4 серия» или «▶ Смотреть снова»; «С начала»; «Похожие»; кнопки озвучки, качества и субтитров; закладки. Карточка плитки в фокусе подгружается заранее, поэтому открывается быстро.
- **Сезоны и серии** — вкладки сезонов (больше пяти — панель «Сезоны…» по красной кнопке), серии плитками с отметками просмотра; длинные сезоны — частями.
- **Озвучка** — выбор дорожки: тип, студия, язык, звук («Дубляж · Студия Альфа · стерео»). Выбранная студия запоминается как любимая и выбирается в следующих тайтлах.
- **Качество** — «Авто (до 1080p)» или конкретное; верхняя граница — в настройках, 4K — после включения в «Это устройство KinoPub».
- **Субтитры** — «Русские», «Английские», «… · только надписи», «Выключены».
- Озвучку, качество и субтитры можно менять и во время просмотра (кнопки плеера): видео перезапускается с той же позиции.
- **Закладки** — папки закладок KinoPub; добавить или убрать тайтл — кнопкой на карточке.
- **«Продолжить просмотр» и прогресс** — позиция сохраняется в KinoPub во время просмотра, на паузе и при выходе из плеера. С 90 % серия или фильм отмечаются просмотренными. Если связи нет, отметки копятся на телевизоре и отправляются, когда связь вернётся.
- **Автопереход** — в конце серии сразу стартует следующая, в том числе первая серия следующего сезона. Кнопки плеера «предыдущая» и «следующая» тоже переключают серии.
- **Настройки** («Просмотр и аккаунт»):
  - «Воспроизведение» — максимальное качество, язык и тип озвучки, любимые студии, субтитры по умолчанию;
  - «Это устройство KinoPub» — название устройства и 4K;
  - «Аккаунт» — подписка и срок, «Выйти из KinoPub» (с подтверждением);
  - «Для опытных» — способ воспроизведения (HLS1/HLS2), CDN-сервер, AC3, HEVC, буферы старта и продолжения, размер постеров, фоны карточек;
  - «Диагностика».
- **Ошибки** — понятный текст, код `KP-…` и кнопки «Повторить» и «Диагностика» (раздел «Частые проблемы»).

## «Диагностика»

Меню → «Диагностика» (есть и без входа). Здесь проверки Phase 0, отчёт и переключатели развилок. Экран нужен, чтобы один раз проверить приложение на конкретном телевизоре, и при проблемах — чтобы собрать отчёт.

### Проверки на телевизоре (Phase 0)

1. Войти в KinoPub. Без входа работают только CDG-01, CDG-02, CDG-09 и CDG-10.
2. «Запустить проверки API» — строки CDG-01…CDG-04 и CDG-08…CDG-10 получат ✓ или ✗.
3. Плитки воспроизведения — запустить каждую:
   - «Видео: озвучка 1», «Видео: озвучка 2», «Видео: HLS2» — видео стартует, во второй плитке другая озвучка (CDG-05);
   - «Кнопки плеера» — кнопки плеера работают (CDG-06);
   - «События плеера» — посмотреть полминуты, пауза, продолжить, выйти кнопкой «Назад» (CDG-07);
   - «Автопереход серии» — дождаться конца серии: стартует первая серия следующего сезона (CDG-11);
   - «Прокрутка 150 плиток» — листать вниз до догрузки и следить, нет ли рывков (CDG-12).
4. Хранилище (CDG-09): «Записать маркер хранилища» → перезапустить MSX → открыть «Диагностику». Затем выключить телевизор из розетки, включить и снова открыть «Диагностику». Если за это время вышло обновление MSX — открыть «Диагностику» и после него.
5. «Отчёт» — 2–4 страницы крупного текста; листаются кнопками «‹ Стр. n» / «Стр. n ›».

### Web-пробник на компьютере

Часть результатов (схема ответов API, времена) удобнее снять в браузере:

1. Открыть web-версию MSX по ссылке из раздела «Запуск в браузере». Домены KinoPub — через VPN, как у телевизора.
2. «Вход» — создаётся временное устройство KinoPub.
3. «Диагностика» → «Запустить проверки API» → дождаться результатов → «Отчёт в консоль».
4. Открыть консоль браузера (⌥⌘J на Mac, Ctrl+Shift+J на Windows) и скопировать строку, которая начинается с `KPREPORT`.
5. «Диагностика» → «Выйти из KinoPub» → «Выйти» — слот устройства освободится.

### Как отправить отчёт

Сфотографируйте телефоном все страницы «Отчёт» с телевизора и приложите строку `KPREPORT …` из web-пробника. Опишите, что делали и что увидели (экран, код `KP-…`). В отчёте нет токенов, кодов входа и IP-адресов. Отправляйте отчёт в issue репозитория или в чат с разработчиком; в репозиторий отчёты не коммитятся.

### Переключатели развилок

«Диагностика» → «Для разработчика». Значения хранятся на телевизоре, деплой не нужен; «Сбросить все» возвращает значения по умолчанию. Менять — только по итогам проверок (спец. §16.3):

| Переключатель | По умолчанию | Когда менять |
|---|---|---|
| Режим потока (`streamMode`) | `hls1` | CDG-05: `hls1` не стартует → `hls2` (без выбора озвучки) |
| Свойства плеера (`playerPropsIn`) | `resolve` | CDG-06: кнопки плеера не работают → `item` |
| Снимки позиции (`heartbeat`) | `ticks` | CDG-07: тики не приходят → `timer`; без позиции и в нём → `percent` |
| Источник событий (`events`) | `handleEvent` | CDG-07: события плеера не доходят до плагина → `triggers` |
| Автопереход (`autonext`) | `button` | CDG-11: следующая серия не стартует → `resolve` |
| Смена озвучки в плеере (`restart`) | `inplace` | новая озвучка или качество не запускаются в открытом плеере → `eject` (плеер закроется и откроется снова) |
| Префетч по фокусу (`focusPrefetch`) | `on` | CDG-12: рывки при навигации → `off` |
| POST-тела (`postBody`) | `form` | CDG-03: тело POST не принимается → `query` |
| Хост API (`apiBase`, `apiFallbackBase`) | `api.service-kp.com`, `api.srvkp.com` | только если KinoPub сменит адрес API |

Если CDG-01 показал `KP-CORS`, CDG-02 — нет CORS у `/oauth2/*`, хранилище не держит вход даже между обычными перезапусками MSX или события плеера не доходят ни одним способом, клиентская схема не подходит — нужен Plan B (раздел ниже).

## Частые проблемы

**«Нет связи с KinoPub. Проверьте VPN» (`KP-NET`).** Телевизор не достучался до API KinoPub. Проверьте, что VPN на роутере работает и в podkop есть все домены из раздела «Доступ к KinoPub». Уже открытые разделы в это время показываются из кэша с пометкой «нет связи». «Диагностика» → «Запустить проверки API»: ✓ у CDG-01 значит, что API снова доступен.

**«KinoPub не отвечает. Проверьте VPN» (`KP-NET`).** Данные экрана не пришли за 6 секунд: связь висит, KinoPub отвечает медленно или ограничил частоту запросов (429) и повторы ещё идут. Запрос при этом не отменяется: если данные придут позже, экран сам заменится ими. Проверьте VPN, подождите минуту и нажмите «Повторить».

**`KP-NET` в «Диагностике» сразу после обновления.** В течение 10 минут после деплоя телевизор может держать старый `index.html`, а он не принимает новый `probe.js`. Это не сбой сети: перезапустите MSX; если не помогло — подождите 10 минут и перезапустите ещё раз.

**«KinoPub сейчас не отвечает. Повторите через минуту» (`KP-429`).** KinoPub ограничил частоту запросов — обычно когда несколько телевизоров листают каталог одновременно. Приложение само снижает число запросов на 30 секунд. Подождите минуту и нажмите «Повторить». Ошибки KinoPub часто приходят без заголовков CORS, и браузер видит их как обрыв сети; приложение проверяет, жив ли сервер, и считает такой ответ ограничением частоты, а не потерей связи. Если повторы не уложились в 6 секунд, вместо этого экрана будет «KinoPub не отвечает» (выше) — действия те же.

**CORS и `KP-CORS`.** В обычной работе приложение `KP-CORS` не показывает. Строка «KinoPub не разрешает запросы из приложения (CORS)» может появиться только в проверке CDG-01 «Диагностики» — значит, KinoPub перестал разрешать запросы из браузерных приложений. Это не исправить настройками: пришлите отчёт, решение — Plan B.

**«Содержимое недоступно».** Так MSX сообщает, что не смогла показать ответ плагина. Нажмите «Назад» и откройте раздел снова; если не помогло — перезапустите MSX (после деплоя — через 10 минут, см. выше). Если ошибка повторяется на одном и том же экране — это ошибка приложения: запишите, как туда попасть, и пришлите отчёт.

**«Сессия KinoPub завершена, войдите снова» (`KP-AUTH`).** Телевизор не включали больше 30 дней или устройство удалили на `kino.watch`. Нажмите «Войти» и введите новый код.

**«Тайтл недоступен или удалён из каталога» (`KP-404`).** Тайтл убрали из KinoPub. Кнопки «Назад» и «Поиск» — повтор не поможет.

**MSX при старте пишет «status: 0».** Телевизор не загрузил плагин с GitHub Pages: проверьте, что `github.io` идёт через VPN, и откройте в браузере `https://osmaevrsh.github.io/msx/start.json` — там должно быть «KinoPub MSX».

**Видео не стартует.** Приложение само пробует другой способ воспроизведения («Предыдущий запуск не удался — пробую другой способ воспроизведения»). Если видео не идёт стабильно — «Просмотр и аккаунт» → «Для опытных» → «Способ воспроизведения» → «Способ 2 (HLS2)» или другой «CDN-сервер».

**Вход не проходит, кончились слоты.** Удалите неиспользуемые устройства на `kino.watch` и запросите «Новый код».

## Для разработчика

### Локальный запуск

Нужен Node 26.

```bash
npm ci
npm run dev
```

`npm run dev` собирает плагин и пересобирает его при правках в `src/` и `public/`, раздаёт его на `http://127.0.0.1:8080`, поднимает mock API KinoPub на `http://127.0.0.1:8787` и печатает адрес web-MSX:

```text
http://msx.benzac.de/?start=menu:request:interaction:init@http://127.0.0.1:8080/app/index.html
```

Chrome нужно запустить с флагом `--disable-features=LocalNetworkAccessChecks` (или `chrome://flags/#local-network-access-check` → Disabled), иначе страница из интернета не достучится до `127.0.0.1`. В dev-сборке плагин ходит в mock, а не в KinoPub; вход подтверждается сам на третьем опросе кода, телефон не нужен.

### Mock API

`tools/kpmock` — mock API KinoPub на Node с CORS как у боевого API и синтетическими фикстурами (каталог, сериалы с сезонами, закладки, прогресс, OAuth device flow). Отдельно: `npm run mock` (порт 8787). Сбои включаются сценариями: `POST /__mock/scenario` (задержки, 429 и 5xx без CORS, обрывы, зависания, «CORS выключен»), `POST /__mock/reset`; журнал запросов — `GET /__mock/calls`.

### Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сборка с наблюдением, статика :8080, mock :8787 |
| `npm test` | unit, contract и golden-тесты (`node --test`) |
| `npm run typecheck` | `tsc` без сборки |
| `npm run build` | боевая сборка в `dist/`: `app/app.js`, `app/probe.js`, `app/index.html`, `start.json`, `build-info.json` |

### CI и деплой

Workflow `.github/workflows/ci.yml`:

| Задача | Когда | Что делает |
|---|---|---|
| `test` | каждый push в `main` и pull request, ручной запуск | `npm ci`, `typecheck`, `npm test`, `crawl`, `privacy`, `build`, `size` |
| `deploy` | push в `main` после `test`; ручной запуск из `main` с `deploy` (включён по умолчанию) | сборка с адресом Pages, `size`, `upload-pages-artifact`, `deploy-pages` |
| `e2e` | только ручной запуск с `e2e` | Chromium с системными зависимостями, `npm run e2e`; при падении — трейсы Playwright в артефакте `e2e-test-results` |

Ручной запуск: Actions → ci → Run workflow, ветка `main`; поля `sha` (собрать указанный коммит), `deploy`, `e2e`. Например, только e2e — снять `deploy`, включить `e2e`. Секретов нет; у токена workflow только чтение, `deploy` дополнительно получает `pages: write` и `id-token: write`. Зависимости npm кэшируются; install-скрипт esbuild разрешён в `allowScripts` в `package.json`.

### Откат

- `git revert <коммит>` в `main` и push — CI проверит и выложит исправленную версию.
- Или Actions → ci → Run workflow из `main` с полем `sha` нужного коммита — будет собран и выложен он; `main` при этом не меняется.

Телевизоры получат откаченную версию в течение 10 минут (раздел «Установка», «Обновления»).

### Своя копия

1. Форк или новый **публичный** репозиторий `msx` (пустой) и push в него.
2. Включить двухфакторную аутентификацию аккаунта GitHub.
3. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Settings → Environments → `github-pages` → Deployment branches and tags: только `main`.
5. Дождаться зелёного `ci` (если первый `deploy` упал, потому что Pages ещё не были включены, — «Re-run all jobs») и открыть `https://<login>.github.io/msx/start.json`.
6. Что вводить на телевизоре — `npm run tv-address -- <login>`.
