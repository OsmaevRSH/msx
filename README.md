# KinoPub MSX

Interaction plugin для [Media Station X](https://msx.benzac.de/info/), который показывает каталог KinoPub и воспроизводит видео на телевизоре без собственного сервера.

## Что это

- Плагин — статика на GitHub Pages: `https://osmaevrsh.github.io/msx/`. Своего сервера нет: телевизор обращается к API KinoPub напрямую, прогресс просмотра хранится в KinoPub.
- Платформа — Samsung Tizen 2025–2026 с MSX 0.1.165+. Видео играет плеер MSX.
- Библиотека TVX встроена в бандл `app/app.js`, внешних скриптов нет. Экран «Диагностика» (пробник и отчёт) — отдельный `app/probe.js`, он загружается при первом открытии.
- Сейчас идёт **Phase 0 «Пробник»**: на телевизоре проверяется, как работают вход, запросы к API, хранилище, плеер и его события. По итогам выбираются значения переключателей (`docs/architecture-client.md` §16). Остальные разделы меню в разработке.

## Установка на телевизор

1. Samsung Apps → **Media Station X** → установить.
2. Settings → Start Parameter → Setup → ввести `osmaevrsh.github.io` и включить **замок** (https).
3. MSX покажет «KinoPub MSX» → подтвердить.
4. «Вход»: на телефоне открыть `kino.watch/device` и ввести код с экрана телевизора.
5. «Диагностика» — пробник Phase 0 (ниже).

Второй телевизор — те же шаги, свой вход и своё устройство KinoPub.

Что вводить для другого логина GitHub или другого имени репозитория, печатает `npm run tv-address -- <login> [repo]`. Если в логине есть дефис, при вводе с пульта он превращает следующую букву в заглавную. Тогда, если адрес на экране не совпал, нужна короткая ссылка `id:igd:<alias>` на is.gd — команда объясняет, как её сделать.

**Обновления.** Новая версия доходит до телевизора за 10 минут после деплоя, а MSX, открытая дольше, держит старую до перезапуска. В эти же 10 минут «Диагностика» может открыться экраном ошибки `KP-NET`. Это не сбой сети: перезапустите MSX; если не помогло — подождите 10 минут и перезапустите ещё раз.

## Phase 0: чек-лист

### Перед началом

- [ ] На `kino.watch` открыть список устройств и удалить неиспользуемые: каждый телевизор занимает свой слот (около 5 на аккаунт), web-пробник на компьютере — ещё один, временный.
- [ ] В podkop добавить `github.io` и `benzac.de` (словарь и ресурсы самой MSX).
- [ ] Репозиторий опубликован и Pages включены (раздел «Публикация»); в браузере открывается `https://osmaevrsh.github.io/msx/start.json`.

### На телевизоре

1. Ввести адрес по разделу «Установка» и сверить строку на экране буква в букву: `osmaevrsh.github.io`.
2. «Вход» — войти в KinoPub. Без входа работают только CDG-01, CDG-02, CDG-09 и CDG-10.
3. «Диагностика» → «Запустить проверки API» — строки CDG-01…CDG-04 и CDG-08…CDG-10 получат ✓ или ✗.
4. Плитки воспроизведения — запустить каждую:
   - «a1», «a2», «HLS2» — видео стартует, во второй плитке другая озвучка (CDG-05);
   - «Свойства из resolve» — кнопки плеера работают (CDG-06);
   - «События и тики» — посмотреть полминуты, пауза, продолжить, выйти кнопкой «Назад» (CDG-07);
   - «Автопереход» — дождаться конца серии: должна стартовать первая серия следующего сезона (CDG-11);
   - «Сетка 150» — листать вниз до догрузки и следить, нет ли рывков (CDG-12).
5. Хранилище (CDG-09): «Записать маркер хранилища» → перезапустить MSX → открыть «Диагностика». Затем выключить телевизор из розетки, включить и снова открыть «Диагностика». Если за время Phase 0 вышло обновление MSX — открыть «Диагностика» и после него.
6. «Отчёт» — сфотографировать все страницы.

### Web-пробник на домашнем компьютере

1. Открыть в Chrome `https://msx.benzac.de/?start=menu:request:interaction:init@https://osmaevrsh.github.io/msx/app/index.html`. Домены KinoPub должны идти через VPN роутера, как у телевизора.
2. «Вход» — создаётся временное устройство KinoPub.
3. «Диагностика» → «Запустить проверки API» → дождаться результатов → «Отчёт в консоль».
4. Открыть консоль браузера (⌥⌘J на Mac, Ctrl+Shift+J на Windows) и скопировать строку, которая начинается с `KPREPORT`.
5. «Диагностика» → «Выйти из KinoPub (освободить слот)».

### Как прислать отчёт

В чат — фото страниц «Отчёт» с телевизора и строку `KPREPORT …` из web-пробника. В отчёте нет токенов, кодов входа и IP-адресов. Отчёты в репозиторий не коммитятся.

## Локальный запуск

```bash
npm ci
npm run dev
```

`npm run dev` собирает плагин и пересобирает его при правках в `src/`, раздаёт его на `http://127.0.0.1:8080`, поднимает mock API KinoPub на `http://127.0.0.1:8787` и печатает адрес web-MSX:

```text
http://msx.benzac.de/?start=menu:request:interaction:init@http://127.0.0.1:8080/app/index.html
```

Chrome нужно запустить с флагом `--disable-features=LocalNetworkAccessChecks` (или `chrome://flags/#local-network-access-check` → Disabled), иначе страница из интернета не достучится до `127.0.0.1`.

Проверки: `npm run check` — типы, тесты, «ничего личного», сборка и бюджет размера; `npm run e2e` — Playwright в web-MSX (один раз нужен `npx playwright install chromium`).

## CI и деплой

Workflow `.github/workflows/ci.yml`:

- каждый push в `main` и pull request — `npm run typecheck`, `npm test`, `npm run privacy`, `npm run build`, `npm run size`;
- push в `main` после проверок — сборка с адресом Pages и деплой (`actions/deploy-pages`). Деплой только из `main`, секретов нет;
- откат — `git revert` в `main` или Actions → ci → Run workflow (ветка `main`) с полем `sha`: будет собран и выложен указанный коммит.

## Публикация

Делает владелец репозитория. Достаточно `git` и браузера, `gh` не нужен.

1. На GitHub создать **публичный** репозиторий `msx` — пустой, без README, `.gitignore` и лицензии.
2. Включить двухфакторную аутентификацию аккаунта GitHub, если она ещё не включена.
3. В рабочей копии: `git remote add origin https://github.com/osmaevrsh/msx.git && git push -u origin main`. Для push по HTTPS git попросит вход в GitHub (токен или Git Credential Manager); можно и по SSH: `git@github.com:osmaevrsh/msx.git`.
4. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
5. Settings → Environments → `github-pages` → Deployment branches and tags: разрешена только `main`. Если стоит «No restriction» — выбрать «Selected branches and tags» и добавить `main`.
6. Actions → ci: если первый запуск упал на `deploy`, потому что Pages ещё не были включены, — открыть его и нажать «Re-run all jobs». Дождаться зелёного `ci`.
7. Открыть `https://osmaevrsh.github.io/msx/start.json` — там должно быть «KinoPub MSX».
8. Настроить телевизор по разделу «Установка».
